# Контент

## Состав

- 1480 слов;
- 2668 ассоциаций;
- 2664 WebP-файла;
- 4 ассоциации с `placeholder.png`:
  - doom;
  - furniture;
  - glance (две ассоциации).

Итоговый словарь получен после добавления 7 слов (castle, cave, plumber, butcher, glue, chalk, barber) и исключения 61 слова без ассоциаций.

## Формат

`src/content/words.json`:

```json
{
  "version": 1,
  "generatedAt": "2026-...",
  "words": [
    {
      "id": 1,
      "lemma": "bright",
      "ipa": "braɪt",
      "ruPronunciation": "брайт",
      "meanings": ["яркий"],
      "mnemonics": [
        {
          "id": "1-1",
          "cueWord": "Брат",
          "sceneText": "брат включает...",
          "image": "w1_1_bright.webp",
          "sortOrder": 1,
          "status": "approved"
        }
      ]
    }
  ]
}
```

## Правила

- У слова минимум одна ассоциация.
- `sortOrder` задаёт порядок вариантов.
- `image` — имя файла в `public/images/words`.
- `placeholder.png` означает отсутствие иллюстрации.
- Менять `id` слов нельзя: к ним привязаны карточки и прогресс.
- Новые слова добавляются в конец и получают новые id.

## Изображения

- Формат: WebP.
- Путь: `public/images/words/<filename>`.
- Публичный URL: `/images/words/<filename>`.
- `imageUrl()` подставляет placeholder для пустого имени или `placeholder.png`.

Промпты для генерации иллюстраций лежат в исходном проекте:

- `nano_banana_prompt_rules_for_llm.md`;
- `STAGE_2/prompts_nano_banana/`: 296 листов 3×3 + один лист 2×2 на 2668 ячеек.

## Проверка

```bash
pnpm test
```

Тест проверяет:

- 1480 слов и 2668 ассоциаций;
- уникальность id;
- наличие перевода и хотя бы одной ассоциации;
- существование файлов изображений;
- ровно 4 плейсхолдера.

## Незавершённое

Порядок выдачи слов пока соответствует JSON. Решено, но не реализовано:

- тематическая группировка + фонетическое распределение;
- размеры занятий 5/10/15/20;
- окно 20 слов;
- конфликт по всем выбранным ассоциациям;
- префикс из 3 букв;
- исключение для родственных слов.
