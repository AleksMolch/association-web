# ADR 0005: Контент в JSON, а не в БД

## Контекст

Словарь и иллюстрации одинаковы для всех пользователей и меняются деплоем.

## Решение

Хранить `words.json` и WebP в репозитории; в БД хранить только `wordId` и прогресс.

## Почему

- Нет JOIN с контентом на каждый запрос.
- Контент версионируется вместе с кодом.
- Легко проверять тестами.
- Изображения отдаются статически/CDN.

## Последствия

- Нельзя редактировать словарь через админку.
- Удаление/изменение `wordId` ломает прогресс.
- Нужен контент-тест и аккуратная миграция при изменении схемы.
