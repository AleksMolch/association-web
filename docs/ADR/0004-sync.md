# ADR 0004: Last-write-wins синхронизация по rev

## Контекст

Прогресс создаётся офлайн в браузере, затем переносится в облако. Нужен простой и предсказуемый протокол.

## Решение

- Карточки синхронизируются по `rev`.
- Выборы и настройки — last-write-wins.
- Отзывы — append-only с идемпотентными id.
- Сервер не пересчитывает FSRS.

## Почему

- Просто и достаточно для одного пользователя на нескольких устройствах.
- Нет блокировок и фоновых очередей.
- Легко тестировать.

## Последствия

- При одновременном обучении на двух устройствах более старый снимок проигрывает.
- Нет merge на уровне отдельных полей.
- Для сложных конфликтов потребуется CRDT/журнал операций.
