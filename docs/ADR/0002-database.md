# ADR 0002: Drizzle ORM и PostgreSQL

## Контекст

Нужны typed-запросы, транзакции для платежей и SQL-миграции без тяжёлого runtime.

## Решение

Drizzle ORM + postgres.js + PostgreSQL 16.

## Почему

- Схема и типы в TypeScript.
- Прозрачный SQL и индексы.
- Транзакции для активации подписки.
- Хорошо работает с Better Auth adapter.

## Последствия

- Нужно вручную поддерживать миграции.
- Схема контента остаётся в JSON, без FK.
- Для сложной аналитики потребуются отдельные запросы/витрины.
