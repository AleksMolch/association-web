# ADR 0003: Разовая оплата и webhook-only VIP

## Контекст

Нужен платный VIP без хранения карточных данных и без доверия return URL.

## Решение

- Разовая предоплата через ЮKassa redirect.
- Сумма и срок — только на сервере.
- VIP активирует только webhook `payment.succeeded`.
- Автопродление не реализовано.

## Почему

- Меньше PCI-риска: карты остаются у ЮKassa.
- Return URL можно подделать, webhook — нет (при проверке IP).
- Идемпотентность по `provider_payment_id`.

## Последствия

- Пользователь продлевает вручную.
- Нужен публичный HTTPS webhook.
- Возвраты выполняются вручную.
- Для recurring billing потребуется отдельный ADR и токены автоплатежа.
